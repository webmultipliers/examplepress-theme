=== ExamplePress ===

== Description ==

ExamplePress is a code-first WordPress theme that replaces the traditional template hierarchy with a single-entry-point router. All requests flow through one universal template which dispatches to modular Blockstudio components based on query context.

Requires the Blockstudio plugin (v7.1+).
